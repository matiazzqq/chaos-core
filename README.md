## 🔥 О игре

**CHAOS CORE** — пятая и финальная игра вселенной **CHAOS REALM**. Это босс-битва, объединяющая механики всех предыдущих частей:

- 👾 **Дроны** телепортируются и стреляют (из Void Shooter)
- 🦠 **Вирусы** преследуют и взрываются (из Void Shooter)
- 🧱 **Стены данных** появляются из ниоткуда (из Data Breach)
- 📺 **Глитч-эффекты** трясут экран (из всех игр)

У ядра **3 фазы**:
1. 💀 **Фаза 1**: 5 пуль веером, спавн дронов.
2. 💀 **Фаза 2**: 7 пуль, больше врагов, чаще телепорт.
3. 🔥 **Финальная фаза**: 9 пуль, орды врагов, хаос.

---

## ✨ Особенности

- 👹 **Эпичный босс**: огромное ядро с глазом, следящим за игроком.
- 🎯 **3 фазы**: каждая меняет паттерн атак.
- 🌀 **Телепортация босса**: он не стоит на месте.
- 👾 **Спавн миньонов**: ядро призывает врагов.
- ⚡ **Рывок**: уклоняйся от вееров пуль.
- 📺 **Глитч-атмосфера**: тряска, сканлайны, красная виньетка.
- 🔊 **Индустриальный звук**: всё через Web Audio API.
- 📱 **Тач-поддержка**.
